# 拉链生成插件 使用说明

## 一、功能简介

本插件用于在两个「对象组」（如两条骨骼链、两排定位器、两列模型等）之间生成「拉链」效果：
生成的一排输出骨骼会根据权重算法，在对象A与对象B的对应物体之间平滑切换位置和旋转，
形成类似拉链齿交错、波动的效果。

输出骨骼由**矩阵节点（blendMatrix + decomposeMatrix）**直接驱动位移（translate）和旋转（rotate），
不再使用 parentConstraint 约束，因此不会出现旋转翻转（flip）的问题。

## 二、使用方法

1. 打开插件窗口（工具架按钮「拉链生成」或菜单「卷曲工具 -> 拉链生成」）。
2. 在场景中**按顺序**选择对象A的各个物体（选择顺序即一一对应的顺序），
   点击「对象A」后面的「加载」按钮。
3. 在场景中**按顺序**选择对象B的各个物体，点击「对象B」后面的「加载」按钮。
4. 对象A与对象B的**数量必须一致**（例如都是 5 个），否则无法生成。
5. 点击「生成拉链」按钮。

> 说明：
> - 「按顺序选择」：使用 Shift 加选时，选择顺序会被保留并写入文本框；
>   对象A的第 1 个对应对象B的第 1 个，以此类推。
> - 「任意类型均可加载」：关节（joint）、定位器（locator）、组（group）、
>   曲线、网格、控制器等任意 DAG 物体都可以加载，不再局限于关节链。

## 三、生成结果

- `Zipper_all_Grp_N`：本套拉链的顶层组（N 为自动编号）。
  - `Zipper_Top_ctrl_Grp1_N`：总控制器所在组。
    - `Zipper_Top_ctrl_C_N`：**总控制器**（所有属性都在这里）。
  - `Zipper_output_J_N_all_skin_joint`：输出骨骼组。
    - `Zipper_output_J_N_i`：第 i 个输出骨骼（由矩阵驱动）。
- `Zipper_blendMatrix_N_i` / `Zipper_decomposeMatrix_N_i`：矩阵混合/分解节点。
- `Zipper_expr_N_i`：权重表达式节点。

## 四、属性功能介绍

以下属性都创建在**总控制器 `Zipper_Top_ctrl_C_N`** 上：

### 1. clamp
- 类型：double，默认 1.0
- 作用：权重输出值的上下限钳制范围。
  最终权重会在 `-clamp` 到 `+clamp` 之间被截断，避免数值过大导致异常跳动。

### 2. base_weight
- 类型：double，默认 1.0
- 作用：基础权重倍数（整体强度）。
  数值越大，拉链波动幅度越大；设为 0 时输出骨骼将停留在对象A的位置。

### 3. number_objects
- 类型：long，默认 -1
- 作用：覆盖实际使用的对象数量。
  默认 -1 表示使用实际加载的对象数量；
  设为正数时会用该数值参与前端/后端收缩计算（用于整体缩放收缩范围）。

### 4. time
- 类型：double，默认 0.0
- 作用：时间（相位）参数。
  动画中改变该值可让拉链波动沿链条传播，产生动态效果。

### 5. frequency
- 类型：double，默认 0.1
- 作用：波动频率。
  数值越大，波动越快/越密；数值越小，波动越平缓。

### 6. range
- 类型：double，默认 1.0
- 作用：相邻对象之间的相位差（相位偏移系数）。
  用于在对象之间错开相位，形成连续的波浪。
  > 注意：该值已做 1/100 缩放，即实际参与计算的是 `range * 0.01`，
  > 便于精细调节（改动 1 个单位只影响原值的百分之一）。

### 7. shrink_remapping
- 类型：double，默认 1.0，范围 0 ~ 1
- 作用：收缩重映射基线。
  用于在前端/后端收缩时，将正弦结果重新映射到该基线之上（值越大收缩越不明显）。

### 8. front_shrink
- 类型：double，默认 0.0
- 作用：前端收缩的起始索引偏移。
  控制链条前端从哪个位置开始收缩。

### 9. front_shrink_magnification
- 类型：double，默认 0.0
- 作用：前端收缩的放大倍数。
  值越大，前端收缩效果越强；为 0 时前端不收缩。

### 10. back_shrink
- 类型：double，默认 0.0
- 作用：后端收缩的起始索引偏移。
  控制链条后端从哪个位置开始收缩。

### 11. back_shrink_magnification
- 类型：double，默认 0.0
- 作用：后端收缩的放大倍数。
  值越大，后端收缩效果越强；为 0 时后端不收缩。

---

此外，每个**输出骨骼 `Zipper_output_J_N_i`** 上还有一个独立属性：

### offset（每个输出骨骼上）
- 类型：double，默认 0.0
- 作用：该输出骨骼的额外相位偏移。
  用于对单个骨骼单独微调相位。

## 五、算法说明（简）

对第 i 个输出骨骼，其混合权重大致为：

```
out = clamp(-clamp, clamp,
            frontFactor * backFactor * base_weight *
            sin(frequency * time * 2π + range*0.01 * i + offset))
weightB = 1 - clamp(0, 1, out)
```

输出骨骼矩阵 = 对象A矩阵 * (1 - weightB) + 对象B矩阵 * weightB，
再由 decomposeMatrix 分解出 translate 与 rotate 直接驱动输出骨骼。
